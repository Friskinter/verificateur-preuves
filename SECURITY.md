# Signaler une faille

Si vous pensez avoir trouvé une faille dans ce vérificateur (une preuve fausse déclarée « conforme »,
une preuve valide refusée, ou un problème dans la liste des clés), écrivez à Frisk par le formulaire
[www.frisk-prevention.fr/contact](https://www.frisk-prevention.fr/contact), objet « Autre demande », en
commençant votre message par « Sécurité – vérificateur ». N'ouvrez pas de ticket public tant que le
problème n'est pas corrigé.

Indiquez la version du vérificateur, la commande lancée et le résultat obtenu. N'envoyez pas de document
unique réel ni de données personnelles : un exemple reconstruit suffit.

Une clé de Frisk compromise est révoquée dans la liste des clés (date et motif), jamais retirée, et la
révocation est publiée le même jour ici et sur le site.
